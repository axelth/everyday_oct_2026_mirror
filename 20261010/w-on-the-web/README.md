# w-on-the-web

## Overview
Completly unsafe webapp that aims to expose the same information as the `w` command
on in a web page.
This should never be exposed to anything but the most friendly of networks.

uv was used to create the project folder structure, but the implementation should be Python stdlib and posix tools only.

## The w command
w - Report logged in users and what they are doing

- path: /usr/bin/w
- package: procps
- Homepage: https://gitlab.com/procps-ng/procps

The `w` command on Ubuntu 26 where this web app is developed has several output
options, but we will only aim to recreate the default output
```sh
$ w
 16:40:27 up 6 days,  6:50,  1 user,  load average: 0.54, 0.36, 0.28
USER     TTY      FROM             LOGIN@   IDLE   JCPU   PCPU  WHAT
axel     tty2     -                04Oct26  5days  0.05s  0.04s /usr/libexec/gnome-session-init-worker ubuntu

```
According to `man w`, the following is displayed.

>        The header shows, in this order, the current time, how
>        long the system has been running, how many users  are  currently  logged
>        on, and the system load averages for the past 1, 5, and 15 minutes.
> 
>        The  following  entries are displayed for each user: login name, the tty
>        name, the remote host, login time, idle time, JCPU, PCPU, and  the  com‐
>        mand line of their current process.

Were `JCPU` is the time used by all processes attached to the tty (excluding past background jobs), and `PCPU` is the time used by the process shown in the `WHAT` column.
